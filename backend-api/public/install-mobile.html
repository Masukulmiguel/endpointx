Como funciona

Este registo liga o dispositivo à rede corporativa para gestão de conformidade e segurança. Não recolhe mensagens privadas, passwords, fotografias nem teclas digitadas.

Android iPhone / iPad BYOD Corporativo

Após o registo, o administrador pode aprovar, limitar ou colocar o dispositivo em quarentena (Zero Trust).
