Como funciona

Este registo liga o dispositivo à rede corporativa para gestão de conformidade e segurança. Não recolhe mensagens privadas, passwords, fotografias nem teclas digitadas.

Android iPhone / iPad BYOD Corporativo

Após o registo, o administrador pode aprovar, limitar ou colocar o dispositivo em quarentena (Zero Trust).

Registar dispositivo

Instalar no telemóvel

Para o EndpointX ficar no sistema do telemóvel (como uma app no ecrã inicial), instale-o abaixo. O registo permanece no servidor até o administrador o remover — sobrevive a reinícios e actualizações.

iPhone/iPad: toque em Partilhar → Adicionar ao Ecrã Inicial.

Presença: o dispositivo fica online enquanto a app/página estiver aberta, e volta ao online de imediato ao reabrir. Browsers não enviam heartbeats com a app totalmente fechada (limitação do sistema operativo — iOS/iPadOS não permitem execução em segundo plano). Ao reabrir, sincroniza na hora.

Administração (MDM)

Para gestão avançada, use um MDM suportado:

  • Android Enterprise
  • Apple Business Manager / MDM
  • Microsoft Intune
  • Jamf Pro

Estado inicial: PENDING → aprovação no dashboard EndpointX.
