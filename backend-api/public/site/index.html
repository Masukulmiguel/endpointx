Host Evaluation Risk Monitoring Engine Security. Observa, analisa e recomenda — nunca explora hosts de forma ofensiva.

Princípios de privacidade e segurança

Desenhado para equipas que levam a sério a defesa de endpoints.

✓
Só endpoints autorizados Só dispositivos registados, com agente e ranges CIDR configurados pelo admin.
✓
Sem recolha invasiva Sem palavras-passe, keystrokes ou conteúdo de ficheiros.
✓
Evidência e auditoria Cada conclusão tem fonte, confiança, timestamp e rasto em audit logs.
✓
Aprovação humana Remediação disruptiva requer aprovação de administrador.
